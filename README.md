# 🚀 Thumba to Space - From Thiruvananthapuram to the Stars

### What is it?
An interactive web experience that tells India's space story - starting from the small fishing village of Thumba, Kerala (near magnetic equator) to Chandrayaan-3 Moon landing and beyond.

### Why I Built It?
I am from Kilimanoor, Kerala - close to Thumba where ISRO started in 1963. I wanted to show our journey in a fun, interactive way for students.

### Features
- ⏱️ Gaganyaan Countdown
- 🚀 Kilimanoor Rocket Builder - Launch your name
- 🛰️ LIVE ISS Tracker - Real position via API
- 🌌 NASA APOD - Daily space image
- 🎬 Embedded Space Videos + M83 Music
- 🧠 ISRO Quiz - 5 questions
- 📅 Timeline Slider 1963-2026
- 🔴 Mars & Moon Explorer
- 🌱 Kuttan the Tree-Naut - Companion

### Tech Stack
- Python + Flask (No sleep service)
- NASA APOD API, Open-Notify ISS API
- HTML/CSS - Space Theme
